# Data Science Projects

This repository contains three data science projects which cover classification, exploratory data analysis (EDA), regression, and model evaluation using real-world datasets and Python libraries.

---

##  Projects Overview

### 1. Iris Flower Classification

**Objective:**  
Develop a machine learning classification model to predict the species of an iris flower based on its physical measurements.

**Dataset:**  
The Iris dataset is available directly from `scikit-learn`, so no external download is required.

**Features:**
- Sepal length
- Sepal width
- Petal length
- Petal width

**Target Classes:**
- Setosa
- Versicolor
- Virginica

**Work Performed:**
- Loaded the Iris dataset using `sklearn.datasets`
- Performed exploratory data analysis (EDA)
- Checked dataset shape, data types, missing values, and descriptive statistics
- Visualized feature distributions using pair plots and box plots
- Analyzed the importance of features for species classification
- Split the dataset into training and testing sets
- Trained multiple classification models
- Evaluated models using accuracy, confusion matrix, precision, recall, and F1-score
- Compared model performance and selected the best-performing classifier

**Models Used:**
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

### 2. Unemployment Analysis in India

**Objective:**  
Analyze unemployment trends in India to understand regional variations, monthly patterns, and the impact of the COVID-19 pandemic on unemployment rates.

**Dataset:**  
Unemployment in India dataset, publicly available on Kaggle.

**Work Performed:**
- Loaded and inspected the dataset using pandas
- Cleaned the data and handled missing values
- Converted date columns into appropriate datetime formats
- Analyzed region-wise average unemployment rates
- Studied monthly and time-based unemployment trends
- Visualized unemployment trends for major states and regions
- Identified the top 10 states with the highest average unemployment rates
- Analyzed relationships between unemployment rate, employment rate, and labour participation rate using a correlation heatmap
- Compared unemployment rates before and after the COVID-19 pandemic

**Visualizations:**
- Time-series line charts
- Bar charts for state-wise unemployment rates
- Correlation heatmaps
- Monthly and regional trend analysis

---

### 3. Car Price Prediction

**Objective:**  
Build machine learning regression models to predict the selling price of used cars based on their characteristics.

**Dataset:**  
Vehicle dataset from CarDekho, publicly available on Kaggle.

**Features Used:**
- Car name and brand
- Manufacturing year
- Present price
- Selling price
- Kilometers driven
- Fuel type
- Seller type
- Transmission
- Number of previous owners

**Work Performed:**
- Loaded and explored the dataset
- Handled missing values and duplicate records
- Cleaned inconsistent categorical values
- Extracted car brands from car names
- Calculated car age from manufacturing year
- Analyzed selling price distributions and relationships between features
- Encoded categorical variables using appropriate encoding techniques
- Visualized feature correlations
- Split data into training and testing sets
- Trained and compared multiple regression models
- Evaluated models using MAE, RMSE, and R² score
- Visualized feature importance for the best-performing model

**Models Used:**
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
